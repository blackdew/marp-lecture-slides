# 강의 요구사항 정의서

## 기본 정보

| 항목 | 내용 |
|------|------|
| 강의명 | 에이전트와 함께하는 삶의 전환 |
| 대상 | 비전공자 (30대~60대) |
| 형식 | 4주 연속 과정, 주 1회 2시간, 온라인 |
| 1주차 날짜 | 2026년 11월 |
| 실습 도구 | ChatGPT 데스크탑 앱의 **Codex** |

## 수강 대상 특성

- **구성**: 개발 경험이 없는 성인. 연령대가 30대부터 60대까지 넓음
- **AI 경험 수준**: 챗봇은 써봤으나 설치형 에이전트는 처음
- **전제하지 않는 것**: 터미널, 명령어, 복사·붙여넣기 숙련도, 영어
- **핵심 니즈**: "나도 할 수 있다"는 확신과, 집에 가서 혼자 켤 수 있는 시작점

## 전체 핵심 메시지

> 에이전트와 함께하는 삶의 전환을 오늘 당장 시작하자.

4주 전체가 이 한 문장을 향합니다. 1주차는 그 가운데 **동기부여와 생각의 전환**을 맡습니다.

## 1주차 목표

1. 에이전트가 이미 사람이 못 하던 일을 해내고 있다는 걸 사례로 안다
2. 챗봇과 에이전트가 무엇이 다른지 한 장으로 구분한다
3. 배운 적 없는 일을 직접 시켜서 결과물을 받아본다
4. 필요한 것은 기술이 아니라 **의지**라는 걸 납득한다
5. 집에 가서 혼자 켤 수 있는 상태가 된다

## 설계 원칙

### 슬라이드

- 한 장에 **상징적인 그림 하나 + 문장 하나**. 글을 많이 넣지 않는다
- **비유를 쓰지 않는다.** 쉬운 문장을 쓰되 어설픈 비유로 한 겹 더 얹지 않는다
- 목록은 **명사형으로 끝낸다.** 서술형 문장을 남발하지 않는다
- 기술 설명은 슬라이드가 아니라 강사가 말로 한다
- 모든 사실에는 출처 링크 또는 발표자 노트의 근거를 붙인다

### 실습

- 터미널을 다루지 않는다. GUI 앱만 쓴다
- 바탕화면에 빈 `1주차` 폴더를 만들고 거기서만 작업한다 (안전장치)
- 과제마다 **그대로 따라 칠 수 있는 프롬프트**를 화면에 띄운다
- 한 번에 안 되는 게 정상이라는 걸 명시적으로 가르친다

## 시간 배분 (120분)

| 친구들 이야기 | 14분 | 비전공자 네 명의 사례 |

| 쉬는 시간 | 10분 | |
| 쓰는 법 + 실습 | 31분 | Codex 사용법 8단계, 과제 4개 |
| 마무리 | 9분 | 의지와 방법, 이번 주 과제 |

## 산출물

| 파일 | 용도 |
|------|------|
| `week1.html` | **발표용 본 슬라이드.** 발표자 노트 토글(N), 16:9 자동 맞춤, 휴대폰 문서 모드 |
| `lecture.md` / `lecture.html` | Marp 판. PDF·PPTX 출력과 포털 등재용 |
| `_build/` | 두 형식을 모두 뽑는 생성기 (원본은 `w1.py` 하나) |

## 성공 기준

- 수강생 전원이 자기 폴더에 **결과물 파일 하나**를 남기고 끝낸다
- "웹페이지를 어떻게 만드는지 아는 분?"에 아무도 손을 못 들었는데 모두 만들어낸 상태가 된다
- 집에 가서 매일 한 번 켜볼 마음이 생긴다
