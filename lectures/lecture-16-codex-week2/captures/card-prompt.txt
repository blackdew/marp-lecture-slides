첨부한 두 그림을 활용해, 40년 된 친구에게 보내는 새해 연하장을 웹페이지로 완성해줘.

받는 사람: [받는 사람]

디자인과 문구는 아래 내용으로 확정했으니, 추가 확인 없이 제작과 검증까지 진행해줘.

1. 디자인
- 「눈 내린 마을.png」를 화면 전체 배경으로 사용해줘.
- 배경 위에 밝고 따뜻한 편지지를 겹쳐 인사말이 선명하게 보이게 해줘.
- 「눈사람.png」는 편지 아래쪽에 작은 우표 같은 장식으로 넣어줘.
- 그림의 분홍빛 햇살과 민트색을 살려 차분하고 따뜻하게 꾸며줘.
- 제목은 한글 명조체, 본문은 읽기 쉬운 고딕체를 사용해줘.
- 휴대폰에서 열자마자 인사말이 보이게 하고, 인사말 본문은 컴퓨터에서 28px, 휴대폰(화면 너비 600px 이하)에서 26px, 작은 휴대폰(360px 이하)에서 24px로 크게 표시해줘. 본문 줄 간격은 글자 크기의 1.75배로 하고, 작은 휴대폰에서는 1.7배로 해줘.
- 제목도 함께 크게 표시해줘. 컴퓨터에서는 clamp(32px, 4vw, 40px), 휴대폰에서는 33px, 작은 휴대폰에서는 29px를 사용해줘.
- 마지막 “새해 복 많이 받아!”는 컴퓨터에서 34px, 휴대폰에서 32px, 작은 휴대폰에서 29px로 표시해줘.
- 가능하면 휴대폰 한 화면에 담되, 큰 글씨의 가독성을 우선해줘. 작은 화면에서는 한 화면에 맞추려고 글씨를 줄이거나 내용을 자르지 말고, 세로 스크롤로 서명까지 끝까지 읽을 수 있게 해줘.
- 불필요한 버튼, 음악, 애니메이션은 넣지 마.

2. 문구

3. 파일과 검증
- 두 그림을 파일 안에 포함한 독립적인 index.html로 만들어줘.
- HTML 파일 하나만 전달해도 인터넷 없이 그림과 문구가 모두 보이게 해줘.
- 외부 폰트나 라이브러리에 의존하지 말고, 원본 그림 파일은 보존해줘.
- 휴대폰과 컴퓨터 화면에서 이미지 표시, 문구와 서명, 가로 넘침, 내용 잘림을 확인해줘.
- 실제로 확인하지 못한 항목은 확인했다고 말하지 마.
- 완성한 HTML 파일을 바로 열거나 내려받을 수 있는 링크로 제공해줘.
